## 1. 近期 JD 共性信号

从近期公开 JD 和职位页看，大模型应用开发岗位的要求正在从“会调 LLM API / 会写 Prompt”升级到“能把 Agent/RAG 做成可上线、可观测、可治理的工程系统”。

### 1.0 2026-06-08 外部信号复核

本轮复核了公开招聘 JD、技术社区面经/题单和 Agent 协议趋势，新增结论如下：

| 新信号 | 代表来源 | 对复习权重的影响 |

### 1.1 趋势到面试落点

所有新趋势统一答法：

```text
边界是什么 -> 风险是什么 -> 证据字段是什么 -> 失败怎么回滚。
```

| 趋势 | 30 秒主答 | 项目证据 | 代码题落点 | 系统设计变体 |
|---|---|---|---|---|
| Agent 成功率 | 先定义任务成功，再按规划、检索、工具、权限、模型输出分层归因 | trace、任务成功率、人工接管率、失败样本 | agent max-step / retry controller | Agent 编排加评测、人工接管和失败归因看板 |
| RAG 评测回归 | 评测不是只看答案像不像，要看召回、faithfulness、引用和无答案 | golden set、bad case 回归、引用覆盖率 | trace span builder / eval runner | RAG 发布门禁和 bad case 回流平台 |
| MCP / A2A | MCP 连工具和资源，A2A 做 Agent 间委派，二者都不替代权限治理 | 工具白名单、委派审计、授权范围 | tool risk classifier | 身份传递、授权范围、委派审计、结果验收 |
| Data Agent | 难点是指标口径、SQL 安全、权限和图表解释，不是生成 SQL 一行 | Metric Contract、SQL validator、security pass rate | SQL AST readonly validator | 语义层 + 权限层 + 查询执行 + 图表解释 |
| 浏览器/终端/代码执行 Agent | 高风险执行必须沙箱、白名单、确认、diff 审计和回滚 | 沙箱策略、文件 diff、审批记录 | sandbox path allowlist | 执行 Agent 加 roots、网络边界、快照回滚 |
| Computer Use / Browser Agent | 浏览器 Agent 要把观察和动作都结构化，不能只让模型“看屏幕随便点” | DOM/截图摘要、allowed_domains、action policy、takeover log | browser action guard | 浏览器助手加域名白名单、动作白名单、二次确认和回放 |
| 多模态 / 语音 / 实时 Agent | 关键不是“接了语音模型”，而是低延迟、可打断、可回放、可确认和可降级 | ASR 置信度、turn_id、barge-in 日志、人工确认记录 | streaming event merger / realtime eval gate | 语音客服 / 会议助手 / 屏幕操作 Agent |
| 模型网关 / LLMOps | 模型调用层要做路由、限流、trace、成本、降级和灰度 | 成本看板、模型版本、p95 延迟 | model router / rate limiter | 多租户模型网关 + 评测门禁 + 成本预算 |
| 上下文工程 / Memory | 上下文不是越长越好，要做选择、压缩、结构化状态和敏感信息控制 | history summary、state schema、tool_result 摘要 | conversation compactor / state store | 长任务 Agent 加状态存储、摘要压缩、权限和过期策略 |
| Memory Governance | 长期记忆要有写入策略、用户可见、过期、删除和冲突处理 | memory write log、retention policy、delete audit | memory write policy | 个人助手 / 客服 Agent 加记忆白名单、敏感字段拒写和用户删除 |
| Long-running Agent Job | 办公自动化、运维排障、代码执行和报告生成都可能变成长任务 | job state、checkpoint、cancel log、cost budget | agent job state machine | 作业系统加队列、状态查询、取消、恢复和人工审批 |
| Agent SLO / Alerting | 平台/ToB 岗会追问线上稳定性、告警、事故复盘 | SLO 看板、告警记录、rollback record | slo alert rule / incident join | 质量、稳定性、成本、安全四类 SLO |
