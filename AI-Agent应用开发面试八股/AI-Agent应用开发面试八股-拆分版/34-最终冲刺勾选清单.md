## 7. 开口自测

每道题按下面标准自测：

```text
0 分：说不出来。
1 分：只能说定义。
2 分：能说流程和关键点。
3 分：能结合项目、指标和工程权衡。
```

### 优先练到 3 分的问题

- [ ] 介绍你的项目。
- [ ] RAG 完整链路。
- [ ] RAG 召回不准怎么办。
- [ ] RAG 幻觉怎么处理。
- [ ] Agent 和 Chatbot 区别。
- [ ] Tool Calling 安全怎么做。
- [ ] LangGraph 为什么适合生产 Agent。
- [ ] SSE/asyncio/限流怎么做。
- [ ] 如果 QPS 提升 10 倍怎么办。
- [ ] 如果项目没上线怎么验证效果。

## 8. 旧版压缩句，仅供提前摘入 80

最后 10 分钟不要看本节，直接回 `78-临面当天作战面板.md`。下面 5 句只适合提前摘入 `80-JD实战转化闭环工单.md`，作为上场包里的压缩口径。

```text
1. 大模型应用不是调 API，而是工程治理。
2. 缺知识优先 RAG，缺动作接 Tool，复杂流程用 Agent，稳定行为再考虑微调。
3. Prompt 不是安全边界，权限和工具执行必须由系统控制。
4. RAG 要看召回、排序、生成、引用和评测闭环。
5. Agent 要看状态、工具、终止、恢复、审计和人工确认。
```

然后深呼吸，按结构讲。面试官追问不是坏事，追问说明你有机会把系统讲完整。
