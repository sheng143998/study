### 196. 手写滑动窗口限流

核心代码：

```python
from collections import defaultdict, deque
import time


class SlidingWindowLimiter:
    def __init__(self, limit, window_seconds):
        self.limit = limit
        self.window = window_seconds
        self.events = defaultdict(deque)

    def allow(self, key):
        now = time.time()
        q = self.events[key]
        while q and now - q[0] >= self.window:
            q.popleft()
        if len(q) >= self.limit:
            return False
        q.append(now)
        return True
```

口述收束：

```text
大模型应用里限流不能只按接口，还要按用户、租户、模型、工具和 token quota 做限制，防止成本和上游资源被打爆。
```

### 197. 手写 TTL Cache

核心代码：

```python
import time


class TTLCache:
    def __init__(self):
        self.data = {}

    def set(self, key, value, ttl):
        self.data[key] = (value, time.time() + ttl)

    def get(self, key):
        item = self.data.get(key)
        if item is None:
            return None
        value, expire_at = item
        if time.time() >= expire_at:
            self.data.pop(key, None)
            return None
        return value
```

口述收束：

```text
RAG 缓存 key 必须包含 tenant_id、权限版本、prompt_version、model_name 和检索策略版本，否则可能出现权限泄漏或旧策略污染。
```

### 198. 手写 LRU Cache

核心代码：

```python
from collections import OrderedDict


class LRUCache:
    def __init__(self, capacity):
        self.capacity = capacity
        self.data = OrderedDict()

    def get(self, key):
        if key not in self.data:
            return -1
        self.data.move_to_end(key)
        return self.data[key]

    def put(self, key, value):
        if key in self.data:
            self.data.move_to_end(key)
        self.data[key] = value
        if len(self.data) > self.capacity:
            self.data.popitem(last=False)
```

口述收束：

```text
LRU 可以用于 embedding、检索结果或热点回答缓存，但涉及权限的回答缓存要格外谨慎。
```

### 199. 手写 TopK

核心代码：

```python
import heapq


def top_k(items, k):
    heap = []
    for item, score in items:
        if len(heap) < k:
            heapq.heappush(heap, (score, item))
        elif score > heap[0][0]:
            heapq.heapreplace(heap, (score, item))
    return sorted(heap, reverse=True)
```

复杂度：

```text
时间 O(n log k)，空间 O(k)。
```

口述收束：

```text
小规模精确检索可以这样做，大规模向量检索一般用 HNSW、IVF、PQ 等 ANN 索引。
```

```python
import json


def parse_json_with_repair(raw, schema, max_retry=2):
    text = raw
```

```python
from fastapi import FastAPI, Request
from fastapi.responses import StreamingResponse

app = FastAPI()


async def event_stream(question, request: Request):
    async for chunk in llm.astream(question):
        if await request.is_disconnected():
            break
        yield f"data: {chunk}\n\n"
    yield "event: done\ndata: {}\n\n"
```

### 204. 写一个异步并发执行器

核心代码：

```python
import asyncio


async def run_with_limit(items, worker, limit):
    sem = asyncio.Semaphore(limit)

    async def run_one(item):
        async with sem:
            return await worker(item)

    tasks = [asyncio.create_task(run_one(item)) for item in items]
    return await asyncio.gather(*tasks, return_exceptions=True)
```

口述收束：

```text

```

```python
import re


def validate_citations(answer, docs):
    cited = {int(x) for x in re.findall(r"\[(\d+)\]", answer)}
    valid = set(range(1, len(docs) + 1))
    return cited.issubset(valid)
```

### 206. 写一个 SQL 只读校验

```python
import re

FORBIDDEN = {"insert", "update", "delete", "drop", "alter", "truncate", "create"}


def is_readonly_sql(sql):
    cleaned = re.sub(r"--.*?$|/\*.*?\*/", " ", sql, flags=re.S | re.M)
    tokens = re.findall(r"[a-zA-Z_]+", cleaned.lower())
    return bool(tokens) and tokens[0] in {"select", "with"} and not any(t in FORBIDDEN for t in tokens)
```

口述收束：

### 208. 写一个 Agent loop

核心代码：

```python
def run_agent(user_input, tools, max_steps=8):
    messages = [{"role": "user", "content": user_input}]
    for step in range(max_steps):
        decision = llm.decide(messages, tools=tools)
        if decision.type == "final":
            return decision.answer
        if decision.type == "tool_call":
            tool = tools[decision.name]
            args = tool.schema.validate(decision.arguments)
            result = tool.call(**args)
            messages.append({"role": "tool", "name": decision.name, "content": str(result)})
            continue
        return "无法处理"
    return "步骤过多，已停止执行"
```

口述收束：

```text
max_steps 只是最低限度，还要有超时、重复工具检测、错误次数、权限、人工确认和 fallback。
```

### 217. 如何向业务方解释 Agent 的风险

```text
Agent 的价值是能自动拆解任务和调用工具，但风险也在这里：它可能选错工具、参数不准、重复执行，或者在上下文不完整时做错判断。

所以生产里不能让 Agent 完全自由行动。查询类动作可以自动化，涉及钱、订单、删除、通知、配置修改的动作必须确认、鉴权、幂等和审计。
```

### 219. 如何回答“为什么不是规则系统”

```text
规则系统适合确定性强、边界清楚的判断，比如权限、金额阈值、状态流转。但用户问题往往是自然语言，表达多样，文档内容也经常更新。

所以我会组合使用：大模型负责理解意图、检索知识和生成解释，规则系统负责强一致和高风险判断。不是用大模型替代所有规则。
```

```text
我认为最大的技术债是评测和版本治理。大模型应用里 Prompt、模型、检索策略、工具 schema 都会影响效果，如果没有版本化和稳定评测集，线上 badcase 很难复现，优化也容易凭感觉。

如果重构，我会优先补 Prompt/model/tool/retrieval 版本管理、离线评测集、badcase 平台和灰度回滚能力。
```
