# JD 实战转化闭环工单

> 目标：把一次具体面试从“看资料”推进到“有题单、有模拟、有弱点修复、有上场包”。  
> 核心原则：没有工单，不开始随机刷题；没有复测，不关闭弱点。

适用场景：

- 收到面试通知后，需要把 JD、简历项目和剩余时间压成执行计划。
- 做完模拟面后，需要把评分转成修复动作。
- 临面前，需要把本次面试的关键材料压成一页上场包。

配合文件：

- `48-面试通知速查导航卡.md`：收到通知后的入口。
- `37-JD关键词匹配与投递策略.md`：抽取 JD 关键词。
- `55-公司轮次面试路径卡.md`：确定公司和轮次打法。
- `69-JD到模拟面题单生成器.md`、`52-面试官陪练脚本手册.md`、`41-面试官评分Rubric与回答自检表.md`、`77-模拟面闭环数据看板与弱点修复手册.md`：1 天及以上进入完整模拟闭环时使用。
- `57-模拟面录音复盘与迭代训练手册.md`：录音复盘可选，不是半天主路径。
- `66-面试上场包与成品验收清单.md`：分层验收口径；半天只参考口径，不必打开。
- `78-临面当天作战面板.md`：最后 30 分钟启动。

### 1.1 2026 JD 趋势命中卡

看到这些关键词时，不要只背定义，直接把它们翻译成本轮项目证据。2 小时只选 JD top3 里的 1 条；半天选 2 条；1 天及以上再补到 3 条。

| JD 关键词 | 面试官实际想听 | 30 秒证据句骨架 | 最小证据字段 |
|---|---|---|---|
| LangGraph / workflow / multi-agent | 是否会做可恢复的状态编排 | 我把流程拆成状态节点，每个节点有输入输出契约，失败后能从 checkpoint 恢复或人工接管。 | `state, node, checkpoint_id, retry_count, handoff_reason` |
| MCP / OpenAPI / tool platform | 工具边界是否可控 | 我没有让模型裸调接口，而是通过 schema、权限、风险等级和审计把工具接入收口。 | `tool_name, schema_version, risk_level, approval_id, audit_id` |
| RAG / AI Search / knowledge base | 是否能解释准确率和权限 | 我把召回、重排、引用、ACL 和缓存分层记录，坏 case 能定位到具体阶段。 | `query_id, retriever, topk, rerank_score, doc_acl_version, citation_doc_id` |
| Data Agent / ChatBI / NL2SQL | 是否懂指标口径和 SQL 安全 | 我先固化指标契约，再限制 SQL 只读、limit、权限和超时，避免查错数或越权查数。 | `metric_id, grain, formula_version, readonly, row_limit, timeout_ms` |
| SSE / realtime / voice | 是否会处理实时体验 | 我用事件流拆 partial/final/error/heartbeat，并记录打断、降级和端到端延迟。 | `event_id, event_type, turn_id, latency_ms, cancel_reason, fallback` |
| Eval / observability / LLMOps | 是否有上线闭环 | 我把 trace 接到 eval，用 bad case 回归、灰度 gate 和回滚阈值控制变更风险。 | `trace_id, case_id, dataset_version, judge_version, pass, rollback_version` |
| Cost / latency / model gateway | 是否能做工程取舍 | 我按任务风险路由模型，用缓存、并行、topK 和 token budget 控制成本和 p95。 | `route_reason, model, p95_latency, token_cost, cache_hit_rate, budget` |

## 6. 分层规则

1. 没有填本工单，不允许开始随机刷题。
2. 每套模拟题单必须能追溯到 JD 关键词、轮次目标或简历项目。
3. 2 小时 / 半天只处理 Top2 B/C；1 天及以上再给每个 B/C 项生成弱点修复卡。
4. 弱点没有复测题，不算修复动作。
5. C 复测到 B 只表示脱离危险；B 必须复测到 A / 连续两次稳定 B+ 才允许关闭。
6. 2 小时 / 半天至少准备 1 条生产级证据；1 天及以上再补到 3 条：trace、评测、工具安全、成本延迟、人审回滚任选。
7. 2 小时 / 半天每个项目至少有 1 条真实性证据；1 天及以上再补到 2 条。
