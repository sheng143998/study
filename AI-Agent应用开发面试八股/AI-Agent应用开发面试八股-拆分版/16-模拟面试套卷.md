# 模拟面试套卷

> 用法：每套按真实时间限制练。练习时不要看答案，先口述，再回到专题文档补漏洞。

## 1. 15 分钟一面快问快答

### 适用场景

- HR 后技术初筛。
- 一面快速判断基础。
- 面试官连续抛短问题。

### 时间分配

```text
自我介绍：2 分钟
项目简述：3 分钟
快问快答：8 分钟
反问：2 分钟
```

### 题目

1. 用 1 分钟介绍你做过的一个 AI Agent/RAG 项目。
2. RAG 是什么？
3. Agent 和普通 Chatbot 的区别是什么？
4. LangChain 解决什么问题？
5. LangGraph 和 LangChain Agent 有什么区别？
6. Tool Calling 的流程是什么？
7. 工具调用参数错了怎么办？
8. Prompt injection 是什么，怎么防？
9. 微调和 RAG 怎么选？
10. MCP 是什么？
11. Python GIL 是什么？
12. asyncio 适合什么场景？

### 通过标准

你应该做到：

- 每题 20 到 40 秒能答完。
- 不陷入过细实现。
- 每个概念都能说出“解决什么问题”。
- 至少能主动提到安全、权限、评估中的一个。

### 常见扣分点

- 把 Agent 说成“会聊天的模型”。
- 把 RAG 说成“向量数据库问答”，没有离线/在线链路。
- 说 Prompt 可以保证安全。
- 说微调可以解决实时知识问题。
- 说 MCP 是 OpenAPI 的替代品。

## 2. 45 分钟技术二面

### 适用场景

- 技术二面。
- 项目深挖。
- 大厂大模型应用岗。

### 时间分配

```text
项目介绍：5 分钟
项目深挖：15 分钟
RAG/Agent 八股：10 分钟
后端工程与系统稳定性：10 分钟
反问：5 分钟
```

### 项目深挖题

2. 你负责哪一部分？
3. 项目整体架构是什么？
4. 离线数据链路怎么做？
5. 在线请求链路怎么做？
6. 遇到的最大难点是什么？
7. 你怎么定位问题根因？
8. 做过哪些方案对比？
9. 最终效果如何衡量？
10. 如果重新设计，你会怎么改？

### RAG 追问题

1. 文档怎么切分？
2. chunk_size 和 overlap 怎么选？
3. PDF 表格怎么处理？
4. 召回不准怎么办？
5. 为什么要 hybrid search？
6. rerank 放在哪一步？
7. 权限过滤怎么做？
8. 文档增量更新怎么做？
9. RAG 如何评估？
10. 如何降低 hallucination？

### Agent 追问题

1. Agent 的状态怎么设计？
2. 工具怎么注册？
3. 工具描述怎么写？
4. 工具调用失败怎么办？
5. 怎么防止 Agent 死循环？
6. 高风险工具如何确认？
7. 多 Agent 如何协作？
8. LangGraph 里的 checkpoint 有什么用？
9. Agent 如何评估？
10. 什么时候不该用 Agent？

### 后端工程题

1. FastAPI 如何实现流式输出？
2. SSE 和 WebSocket 怎么选？
3. 模型调用超时怎么办？
4. 如何限流？
5. 如何做缓存？
6. Redis 缓存击穿/穿透/雪崩怎么处理？
7. 如何统计 token 成本？
8. 如何做 trace？
9. QPS 提升 10 倍怎么办？
10. 如何做灰度发布和回滚？

### 通过标准

你应该做到：

- 项目能画出架构。
- 每个难点都能讲“现象、根因、方案、效果”。
- 能主动讲工程约束，而不是只讲模型。
- 能承认边界，例如 RAG 不能完全消除幻觉。

## 3. 60 分钟项目深挖面

### 适用场景

- 主管面前的核心技术面。
- 大厂二面/三面。
- 简历中有 AI Agent/RAG 项目。

### 第一阶段：项目全貌，10 分钟

题目：

1. 你做的项目服务什么业务？
2. 用户是谁？
3. 为什么不用传统搜索/规则系统？
4. 系统上线了吗？日活/QPS/文档量/用户反馈如何？
5. 你负责的模块和贡献是什么？

高分回答结构：

```text
业务背景
  -> 为什么需要 LLM
  -> 架构模块
  -> 我负责什么
  -> 关键指标
  -> 主要难点
```

### 第二阶段：RAG 深挖，15 分钟

题目：

1. 文档从哪里来？
2. 如何处理 PDF、表格、图片、代码块？
3. chunk 策略如何定？
4. embedding 模型怎么选？
5. 向量库选型是什么？
6. 是否有关键词检索？
7. rerank 用什么模型？
8. 如何支持权限？
9. 如何支持热更新？
10. 如何做 badcase 分析？

面试官可能继续追：

```text
召回不准
  -> 是没召回还是排错了？
  -> 怎么证明？
  -> 用了什么指标？
  -> 有没有标注集？
  -> 优化后提升多少？
```

### 第三阶段：Agent/工具调用深挖，15 分钟

题目：

1. 你的 Agent 是否真的需要自主决策？
2. 哪些步骤是固定流程，哪些交给模型？
3. 工具列表如何设计？
4. 工具 schema 怎么写？
5. 参数校验怎么做？
6. 是否允许模型调用写操作？
7. 工具调用日志记录什么？
8. Agent 中断后能恢复吗？
9. 如何处理多轮上下文？
10. 失败后是重试、降级还是转人工？

高压追问：

```text
如果模型调用退款工具两次怎么办？
如果用户没有订单权限怎么办？
如果工具返回敏感字段怎么办？
如果工具超时但实际执行成功怎么办？
```

### 第四阶段：系统稳定性，10 分钟

题目：

1. 整体延迟瓶颈在哪里？
2. 哪些步骤可以并行？
3. 哪些结果可以缓存？
4. 如何控制 token 成本？
5. 如何做服务降级？
6. 如何做模型路由？
7. 如何做监控和报警？
8. 如何做 A/B 实验？

### 第五阶段：复盘与反问，10 分钟

题目：

1. 如果给你两周重构，你会先改什么？
2. 这个项目最大的技术债是什么？
3. 你认为 Agent 应用最难上线的点是什么？
4. 你对团队的 AI 应用建设有什么建议？

## 4. 主管面表达套卷

### 适用场景

- 三面、主管面。
- 更关注判断力、项目 Owner 意识和业务理解。

### 题目

1. 你怎么看 AI Agent 在业务里的价值？
2. 你认为哪些场景不适合上 Agent？
3. 你如何判断一个 AI 项目是否值得做？
4. 你如何平衡准确率、成本和体验？
5. 如果业务方只追求炫酷 Demo，你会怎么沟通？
6. 如果线上效果不稳定，你会怎么推动改进？
7. 你如何设计 AI 应用的评估体系？
8. 你如何看待 LangChain 这类框架？
9. 你如何看待微调、RAG、Agent 的边界？
10. 你未来想在 AI 应用方向深入哪一块？

### 高分表达模板

```text
我会先判断这个场景到底是知识问题、动作问题、还是流程问题。

如果是知识问题，优先 RAG；
如果是动作问题，需要工具调用和权限控制；
如果是复杂流程问题，才考虑 Agent 或 LangGraph；
如果只是输出风格不稳定，先 Prompt，再看是否需要微调。

我不会为了 Agent 而 Agent。生产系统更重要的是可控、可评估、可回滚。
```
