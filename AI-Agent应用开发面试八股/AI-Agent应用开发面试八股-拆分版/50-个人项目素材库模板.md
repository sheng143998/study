# 个人项目素材库模板

> 目标：把自己的真实项目整理成可复用素材库。  
> 面试回答不要只背通用模板，最终要回到你自己的项目证据。

## 1. 使用方式

建议每个项目复制一份本模板：

```text
项目 A：企业知识库 RAG
项目 B：Agent 工具调用平台
项目 C：Python 大模型后端服务
```

每个项目都要能支撑：

```text
简历 bullet
  -> 2 分钟项目介绍
  -> 5 分钟项目答辩
  -> 三层追问
  -> 系统设计迁移
  -> 主管面复盘
```
