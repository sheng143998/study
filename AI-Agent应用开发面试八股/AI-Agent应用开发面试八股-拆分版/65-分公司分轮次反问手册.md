# 分公司分轮次反问手册

> 目标：面试最后 3-5 分钟，问出能体现岗位理解、工程判断和成熟度的问题。  
> 反问不是客套收尾，而是最后一次展示你理解业务、团队和岗位的机会。

配合文件：

- `43-HR主管面行为面回答手册.md`：主管面/HR 面回答。
- `55-公司轮次面试路径卡.md`：公司和轮次路径。
- `61-岗位画像与复习优先级矩阵.md`：岗位类型判断。
- `62-面试现场救场与澄清话术手册.md`：临场收尾。

## 1. 反问总原则

好的反问要满足三点：

```text
和岗位相关
和本轮面试相关
能体现你关注落地和成长
```

不要问得像泛泛聊天：

```text
团队氛围怎么样？
平时忙不忙？
加班多不多？
你觉得我表现怎么样？
```

更好的方式：

```text
团队当前在 AI Agent/RAG 落地时，最核心的挑战更偏效果、成本、稳定性，还是业务系统接入？
```

## 2. 按轮次反问

### 2.1 一面反问

目标：确认技术栈和岗位真实工作。

可问：

```text
这个岗位日常更偏 RAG/Agent 应用交付，还是更偏平台工具建设？
```

```text
团队现在的大模型应用主要使用哪些技术栈，比如 LangGraph、MCP、模型网关或自研工作流？
```

```text
新人加入后，前三个月通常会先负责哪类模块：检索链路、工具接入、后端接口，还是评测平台？
```

避免：

```text
你们用不用 LangChain？
```

原因：太窄，容易像只关心框架。

### 2.2 二面反问

目标：确认复杂问题、系统设计和工程深度。

可问：

```text
团队目前在 RAG/Agent 线上化过程中，最难稳定的是效果评测、工具调用安全，还是成本和延迟？
```

```text
现在 bad case 回流是偏人工复盘，还是已经有比较系统的评测集和回归流程？
```

```text
Agent 工具调用这块，团队更倾向自由 Agent，还是显式 workflow 加模型决策的混合方式？
```

### 2.3 交叉面反问

目标：展示迁移能力和技术视野。

可问：

```text
不同业务线的大模型应用能力，比如模型网关、工具平台、评测和权限，是统一建设还是各业务自己维护？
```

```text
团队判断一个大模型应用是否值得继续投入，主要看哪些业务指标和技术护栏指标？
```

### 2.4 主管面反问

目标：展示业务理解、owner 意识和成长规划。

可问：

```text
如果我有机会加入，您最希望我在前三个月解决哪类具体问题？
```

```text
团队接下来半年在大模型应用方向，最重要的目标是扩大场景覆盖，还是把已有场景做深做稳？
```

```text
这个岗位做到高绩效，通常需要同时具备哪些能力：业务理解、工程落地、模型应用，还是跨团队协作？
```

### 2.5 HR 面反问

目标：确认流程、成长和匹配度，不要暴露负面动机。

可问：

```text
这个岗位后续的面试流程和大概时间节奏是怎样的？
```

```text
团队对这个岗位候选人最看重的长期特质是什么？
```

```text
如果加入后，团队通常会如何帮助新人熟悉业务和技术体系？
```

薪资、加班、职级可以问，但放在合适阶段，表达要成熟：

```text
我也想了解一下这个岗位的职级和薪酬区间，方便判断双方预期是否匹配。
```

## 3. 按公司风格反问

### 3.1 腾讯

关键词：真实用户、体验、稳定性、业务场景。

可问：

```text
团队当前的 AI Agent/RAG 应用更关注提升用户体验，还是提升内部业务效率？
```

```text
在真实用户场景里，团队更关注答案准确率、响应延迟、用户满意度，还是人工转接率？
```

```text
腾讯业务场景比较多，团队会如何判断哪些场景适合 Agent，哪些更适合传统规则或搜索？
```

### 3.2 阿里 / 阿里云

关键词：平台化、多租户、治理、规模化复用。

可问：

```text
团队的大模型应用能力目前是偏单业务交付，还是在建设统一平台能力？
```

```text
模型网关、Prompt 管理、工具接入和评测这些能力，是由团队统一建设还是各业务线自己做？
```

```text
企业客户场景里，当前落地 Agent/RAG 最大的阻碍是数据接入、权限审计、效果评测，还是成本控制？
```

### 3.3 百度

关键词：检索、排序、知识增强、模型边界、评测。

可问：

```text
团队在 RAG/知识增强方向，更关注检索排序优化，还是模型生成质量和评测体系？
```

```text
当前知识库问答的 bad case 主要集中在文档解析、召回排序、引用可信，还是模型幻觉？
```

```text
团队会如何平衡搜索/检索传统能力和大模型生成能力？
```

### 3.4 字节

关键词：指标、实验、效率、成本、代码能力。

可问：

```text
团队评估大模型应用效果时，最核心的业务指标和护栏指标分别是什么？
```

```text
模型、Prompt 或检索策略变更通常怎么做实验、灰度和回滚？
```

```text
如果一个 Agent/RAG 功能效果不错但成本偏高，团队一般如何做取舍？
```

### 3.5 美团 / 京东 / 快手

关键词：业务流程、客服运营、履约效率、ROI。

可问：

```text
团队的大模型应用更多服务客服、运营、履约，还是内部研发效率？
```

```text
在客服/运营场景里，团队最关注的是人工转接率、首次解决率、处理时长，还是用户满意度？
```

```text
对于高风险业务动作，团队现在更倾向 Agent 自动处理，还是人工确认加流程控制？
```

### 3.6 云厂商 / 企业服务

关键词：私有化、多租户、权限、审计、交付。

可问：

```text
客户落地大模型应用时，最常见的阻碍是数据接入、私有化部署、权限安全，还是效果评测？
```

```text
团队是否有统一的 MCP/OpenAPI 工具接入规范，还是根据客户环境定制？
```

```text
企业级场景里，团队对可观测、审计和 SLA 的要求通常到什么程度？
```

## 4. 按岗位画像反问

### 4.1 RAG 岗

```text
团队当前 RAG 系统的主要挑战更偏文档解析、召回排序、引用可信，还是评测闭环？
```

```text
知识库文档更新频率高吗？团队现在怎么处理增量索引、版本和权限过滤？
```

### 4.2 Agent 岗

```text
团队目前的 Agent 更偏自由规划，还是受控 workflow 加工具调用？
```

```text
Agent 工具调用失败、循环调用和高风险操作，目前有哪些线上兜底机制？
```

### 4.3 MCP / 工具平台岗

```text
工具接入目前更多是 OpenAPI 自动生成 Tool，还是需要人工补充业务语义和风险等级？
```

```text
团队对工具权限、审计和版本兼容有统一平台吗？
```

### 4.4 模型网关 / 平台岗

```text
团队的模型网关目前更关注多模型路由、成本治理、Prompt 版本，还是评测灰度？
```

```text
不同业务接入模型时，是否有统一的 quota、trace、cost 和 fallback 机制？
```

### 4.5 Python 后端岗

```text
这个岗位日常更偏 AI 应用业务逻辑，还是偏大模型后端基础设施，比如流式、限流、任务队列和观测？
```

```text
团队目前模型调用、向量库访问和工具调用这些 I/O 链路，是否已经有统一的异步和超时治理？
```

## 5. 反问避坑

### 5.1 不要过早问

- 薪资。
- 加班。
- 晋升。
- 调休。
- 能不能远程。

这些可以问，但更适合 HR 阶段，且要表达成预期匹配，而不是焦虑。

### 5.2 不要显得没做功课

不要问：

```text
你们公司是做什么的？
这个岗位主要干什么？
你们有没有大模型业务？
```

可以改成：

```text
我看到 JD 里提到 RAG、Agent 和工具平台，想确认一下实际工作中这三块的权重大概如何分布？
```

### 5.3 不要挑战面试官

不要问：

```text
你们为什么不用 LangGraph？
你们的技术是不是比较落后？
你们现在方案有什么问题？
```

可以改成：

```text
团队在 Agent 编排上更倾向使用开源框架，还是自研流程引擎？主要考虑的是稳定性、可控性还是和现有系统集成？
```

## 6. 反问组合模板

### 6.1 技术面 3 问

```text
这个岗位实际工作中，RAG、Agent、工具平台、后端工程这几块权重如何？
```

```text
团队当前大模型应用线上化最大的挑战是什么？
```

```text
如果我加入，前三个月最希望我补上的能力或负责的模块是什么？
```

### 6.2 主管面 3 问

```text
团队接下来半年在大模型应用方向最重要的目标是什么？
```

```text
这个岗位做到高绩效，最关键的能力是什么？
```

```text
团队如何衡量一个 AI Agent/RAG 项目是否真正产生业务价值？
```

### 6.3 HR 面 3 问

```text
后续流程和时间节奏大概是怎样的？
```

```text
这个岗位对应的职级和培养路径大概如何？
```

```text
团队对候选人的长期稳定性和成长性最看重什么？
```

## 7. 最终速背

```text
一面反问：
问技术栈、实际工作内容、前三个月模块。

二面反问：
问线上挑战、bad case 回流、评测和治理。

主管面反问：
问业务目标、高绩效标准、团队半年重点。

HR 面反问：
问流程、职级、培养路径和预期匹配。

公司反问：
腾讯问体验和场景。
阿里问平台和治理。
百度问检索和评测。
字节问指标和实验。
美团/京东问流程和 ROI。
云厂商问私有化、权限、审计。
```

反问的本质不是“我还有什么想知道”，而是“我是否理解这个岗位，并且知道自己加入后要解决什么问题”。
