# 个人复习计划生成器

> 目标：根据目标岗位、剩余时间和薄弱项，生成一份可执行的复习计划。  
> 这份文件解决的问题是：材料已经很多了，今天到底先看什么、练什么、背什么。
> 定位：本文件只负责把主链排成日程，不重新发明路线。临战优先级以 `48`、`55`、`80`、`74`、`78` 为准；专题文件只在主链给出时间盒后按需进入。

## 1. 先确定你的面试画像

用 3 个维度定位自己：

```text
目标岗位：RAG / Agent / 工具平台 / Python 后端 / 微调算法 / 平台网关
剩余时间：半天 / 1 天 / 3 天 / 7 天 / 14 天
当前短板：不会讲项目 / 不会八股 / 不会系统设计 / 不会手撕 / 不会英文
```

面试准备不要平均分配。正确顺序一般是：

```text
项目表达 > P0 八股 > 高频追问 > 系统设计 > 手撕代码 > 加分项
```

如果你连项目 2 分钟版都讲不稳，先不要深挖 P2 平台题。面试官通常先从简历入口开始追，入口不稳，后面准备再多也容易散。

## 2. 半天冲刺计划

适合场景：

- 明天或今晚就面试。
- 岗位方向已经明确。
- 没时间系统补课，只能保住核心表达。

### 2.1 通用半天路线

| 时间 | 动作 | 文件 |
|---|---|---|
| 20 分钟 | 先定路线和剩余时间盒 | `48` |
| 30 分钟 | 按岗位/剩余时间分流，决定只补哪 1-2 个专题 | `55` |
| 70 分钟 | 把 JD top3、项目证据、风险兜底写成上场工单 | `80` |
| 60 分钟 | 按时间盒练开口，不扩大战线 | `74` |
| 20 分钟 | 进入临面当天作战面板，停止横向翻资料 | `78` |

半天路线不要再横向打开一串旧文件。专题文件只从 `74` 的半天时间盒里按轮次选 0-2 个；如果 `80` 还没写完，先别补专题。

### 2.2 半天只背这些

必须能开口：

1. 你的项目解决了什么问题？
2. 为什么用 RAG/Agent，而不是普通大模型调用？
3. RAG 的完整链路是什么？
4. 召回不准怎么优化？
5. Agent 工具调用失败怎么办？
6. LangGraph 解决了什么问题？
7. Tool schema 怎么设计？
8. Python 后端如何做流式响应？
9. 如何评估大模型应用效果？
10. 项目上线后最大的坑是什么？

## 3. 1 天复习计划

适合场景：

- 已经有一点基础。
- 需要快速覆盖一面和项目深挖。

### 上午：建立面试入口

| 时间 | 动作 | 文件 |
|---|---|---|
| 09:00-09:25 | 确认临战路径和今天的取舍 | `48` |
| 09:25-09:55 | 按岗位/轮次分流，选出今天只补的重点 | `55` |
| 09:55-11:10 | 写 JD top3 到项目证据的闭环工单 | `80` |
| 11:10-12:00 | 按时间盒练 2 分钟项目、P0 和追问 | `74` |

### 下午：覆盖技术主线

| 时间 | 动作 | 文件 |
|---|---|---|
| 14:00-15:00 | 把项目经历改成可追问证据，不背散点 | `69` |
| 15:00-16:00 | 用公司/岗位方向做专项命中 | `52` |
| 16:00-17:00 | 做一轮实战问答，暴露卡点 | `41` |
| 17:00-18:00 | 把卡点收敛到错题和补强动作 | `77` |

### 晚上：模拟面试

| 时间 | 动作 | 文件 |
|---|---|---|
| 19:30-20:15 | 按验收表自检口径，补最后的证据缺口 | `66` |
| 20:15-20:45 | 回填 `80` 的上场工单，只保留明天会用的句子 | `80` |
| 20:45-21:15 | 进入临面当天作战面板，准备收尾 | `78` |

`16`、`21`、`35` 可以作为余力或历史复盘参考，但 1 天闭环核心是 `48 -> 55 -> 80 -> 74 -> 69 -> 52 -> 41 -> 77 -> 66 -> 78`。

## 4. 3 天复习计划

适合场景：

- 希望稳住一面和二面。
- 能系统补齐 RAG、Agent、后端和项目表达。

### Day 1：主链启动 + 项目/P0

- 上午：`48 -> 55 -> 80`，先把目标岗位、JD top3、项目证据和风险兜底写清楚。
- 下午：`74 -> 项目/P0`，按时间盒练项目 2 分钟版、P0 高频问法和 2 层追问。
- 晚上：回填 `80`，只记录能在面试里直接说出来的证据句。

### Day 2：专题补强 + 实战追问

- 上午：按 `55` 和 `74` 只选最相关专题，不超过 2 个方向。
- 下午：`69 -> 52`，把专题内容落到项目证据和公司专项。
- 晚上：`41 -> 77`，用问答暴露卡点并收敛错题。

### Day 3：复测/公司专项 + 上场启动

- 上午：围绕目标公司或轮次做复测，优先修 `80` 里缺证据的项。
- 下午：`66` 做口径验收，确认项目、P0、风险兜底、反问都能开口。
- 晚上：`78` 进入临面当天作战面板，不再扩展新资料。

完成主链后，最多从 `19` 或 `34` 单点查 1 条漏项；它们不是 3 天路线的一部分。

## 5. 7 天系统计划

适合场景：

- 目标大厂。
- 希望覆盖一面、二面、主管面。
- 当前材料还没系统看过。

| Day | 主题 | 文件 | 产出 |
|---|---|---|---|
| Day 1 | 岗位定位和项目包装 | `37`、`38`、`18`、`20` | 一版定制简历 bullet + 自我介绍 |
| Day 2 | RAG 和向量数据库 | `04`、`30` | 20 个 RAG 问题可开口 |
| Day 3 | Agent 和 LangGraph | `02`、`03`、`29` | 一个 Agent 状态图讲稿 |
| Day 4 | Prompt、Tool、协议 | `05`、`08`、`31` | Tool/MCP 标准回答 |
| Day 5 | Python 后端和手撕 | `07`、`17`、`23` | 5 道代码题可手写 |
| Day 6 | 系统设计和平台题 | `09`、`14`、`32` | 2 个系统设计模板 |
| Day 7 | 模拟面和上场启动 | `13`、`16`、`80`、`78` | 一轮完整模拟 + 上场包压缩 |

## 6. 14 天强化计划

适合场景：

- 想系统冲大厂。
- 基础不差，但表达和项目还不够锋利。
- 需要兼顾中文、英文、代码、系统设计。

### 第 1 阶段：定位和项目改造

Day 1-2：

- `37`：分析目标 JD。
- `38`：找相似岗位案例。
- `20`：改简历 bullet。
- `18`：打磨自我介绍。
- `24`：准备项目答辩讲稿。

产出：

- 1 份目标岗位版简历项目表达。
- 1 个 2 分钟项目讲稿。
- 1 个 5 分钟项目答辩讲稿。

### 第 2 阶段：P0 基础全覆盖

Day 3-5：

- `12`：标准回答三件套。
- `27`：P0 题库。
- `28`：RAG/Agent/Tool P0 回答。
- `29`：LangGraph/Python 后端 P0 回答。

产出：

- 100 道 P0 题能 30 秒开口。
- 每个专题至少准备 3 个项目化例子。

### 第 3 阶段：P1 深挖

Day 6-8：

- `04`、`30`：RAG 进阶。
- `02`、`03`：Agent/LangGraph。
- `05`、`08`、`31`：Prompt/Tool/协议/微调。

产出：

- 能回答连续追问。
- 能说清楚每个方案的 trade-off。
- 能把原理落回项目。

### 第 4 阶段：系统设计和代码

Day 9-11：

- `09`、`14`、`32`：系统设计和平台题。
- `17`、`23`、`33`：代码题和表达加分。

产出：

- 企业知识库系统设计。
- Agent 工具平台系统设计。
- 模型网关系统设计。
- 5-8 道高频代码题。

### 第 5 阶段：模拟面和复盘

Day 12-14：

- `13`：连续追问链。
- `16`：模拟面试套卷。
- `22`：公司专项回答。
- `25`：英文面试回答。
- `34`：最终冲刺清单。
- `35`：复盘和资料更新。

产出：

- 至少 3 轮模拟面试。
- 1 份错题本。
- 1 份临面 2 小时清单。

## 7. 按岗位生成计划

所有岗位都先走同一条主链：

```text
48 -> 55 -> 80 -> 74
```

如果是 1 天及以上，再接：

```text
69 -> 52 -> 41 -> 77 -> 66 -> 78
```

下面只决定“专题补强模块”，不是另一条路线。每个岗位最多选 2 个专题文件进入 `74` 的时间盒，并把最终能说出口的证据回填到 `80`。

### 7.1 RAG 岗

专题补强：

```text
04 / 30 / 14 / 28
```

每天必须练：

- 用 2 分钟讲 RAG 项目。
- 用 1 分钟讲召回优化。
- 用 1 分钟讲评估指标。
- 用 1 分钟讲幻觉治理。

### 7.2 Agent 岗

专题补强：

```text
02 / 03 / 05 / 29
```

每天必须练：

- 用 2 分钟讲 Agent 状态图。
- 用 1 分钟讲工具调用失败处理。
- 用 1 分钟讲 LangGraph 的价值。
- 用 1 分钟讲 Agent 生产风险治理。

### 7.3 MCP / 工具平台岗

专题补强：

```text
08 / 05 / 31 / 32
```

每天必须练：

- 用 1 分钟讲 OpenAPI、RPC、MCP 区别。
- 用 1 分钟讲 Tool schema。
- 用 1 分钟讲工具权限和审计。
- 用 2 分钟讲工具平台架构。

### 7.4 Python 后端岗

专题补强：

```text
07 / 23 / 17 / 29
```

每天必须练：

- 解释 SSE 流式响应。
- 解释 asyncio 和并发控制。
- 手写限流器或 LRU。
- 讲模型接口超时和降级。

### 7.5 微调算法岗

专题补强：

```text
06 / 31 / 04 / 30
```

每天必须练：

- RAG 和微调怎么选。
- LoRA 的适用场景。
- 数据构造和评估集。
- bad case 回流。

### 7.6 平台网关岗

专题补强：

```text
32 / 09 / 14 / 31
```

每天必须练：

- 模型网关架构。
- 多模型路由。
- Prompt 版本和灰度。
- 成本、审计、评测。

## 10. 最小可执行原则

当你时间很少时，不要追求“看完”。只追求：

- 能把项目讲完整。
- 能回答 JD 最相关的 10 个问题。
- 能抗住 2 层追问。
- 能讲一个系统设计骨架。
- 能写 1-2 道常见代码题。
- 能说清楚不会的问题下一步怎么查证和改进。

一句话：

```text
复习计划不是安排阅读量，而是安排面试输出能力。
```
