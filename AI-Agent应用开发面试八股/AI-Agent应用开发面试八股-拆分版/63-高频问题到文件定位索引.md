# 高频问题到文件定位索引

> 目标：面试前或模拟后，遇到一个问题，能在 10 秒内知道该翻哪几份文件。  
> 这份不是新题库，而是“倒排索引”：问题 -> 主文件 -> 补强文件 -> 练习文件。

使用方式：

```text
先定位问题类型
  -> 看主文件补概念
  -> 看标准回答练开口
  -> 看追问/项目/指标文件补防守
  -> 用模拟文件压测
```
