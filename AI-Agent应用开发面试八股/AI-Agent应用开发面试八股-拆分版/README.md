# AI Agent 应用开发面试八股：使用入口

这不是一套从头读到尾的资料，而是一套按面试场景调用的工具箱。先判断你现在处在哪个状态，再打开对应文件。

## 30 秒选择入口

| 你现在的状态 | 先打开 | 目标 |
|---|---|---|
| 第一次打开资料 | `00-阅读索引.md` | 知道全套文件有什么 |
| 不知道该看哪份 | `36-总目录导航图与学习地图.md` | 按岗位、轮次、剩余时间找路线 |
| 资料太多，开始焦虑 | `74-减负版复习路线与抽题清单.md` | 停止乱看，转成口述和模拟 |
| 收到面试通知 | `48-面试通知速查导航卡.md` | 5分钟生成行动路线 |
| 已经确定 JD 和轮次 | `80-JD实战转化闭环工单.md` | 把 JD 变成题单、模拟、修复和上场包 |
| 面试当天 | `78-临面当天作战面板.md` | 最后 30 分钟只激活上场状态 |
| 模拟面之后 | `77-模拟面闭环数据看板与弱点修复手册.md` | 把弱点变成下一轮训练 |

## 最短上场路径

`48` 只用 5 分钟定方向；只要 JD 和轮次明确，之后必须进入 `80` 产出本次工单。

只剩 2 小时：

```text
48 -> 80 -> 74 -> 78
```

还有半天：

```text
48 -> 55 -> 80 -> 74 -> 78
```

还有 1 天：

```text
48 -> 55 -> 80 -> 74 -> 69 -> 52 -> 41 -> 77 -> 66 -> 78
```

还有 3 天：

```text
Day 1: 48 -> 55 -> 80 -> 74 -> 项目/P0
Day 2: 专题补强 -> 69 -> 52 -> 41 -> 77
Day 3: 复测/公司专项 -> 66 -> 78
```

## 使用原则

每次复习都要产出一个能上场的东西：一段 60 秒自我介绍、一个 2 分钟项目入口、一个 RAG/Agent 30 秒答案、一张系统设计图、一次模拟面复盘，或两个反问。

如果你已经连续看了 3 份文件但还说不出口，立刻停看，去 `74-减负版复习路线与抽题清单.md` 抽题口述。
