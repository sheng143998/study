# 公司风格与高频权重表

> 说明：本文件根据公开 JD、牛客面经和大模型应用开发岗位常见要求整理。面经存在样本偏差，不能当作公司官方题库，但可以用来判断复习优先级。

## 1. 总体结论

AI Agent / 大模型应用开发方向的大厂面试，常见组合是：

```text
项目深挖
  + RAG/Agent/Tool Calling 八股
  + 后端工程基础
  + 场景系统设计
  + 代码题或小工程题
```

公开面经里反复出现的题型包括：

- RAG 的完整链路、文本切分、召回优化、知识库热更新。
- Agent 循环、状态管理、工具注册、失败恢复、死循环处理。
- 多 Agent 编排、计划模式、工具调用安全。
- SSE 流式输出、多模型接入、缓存、限流、降级。
- Python/Java 后端基础、Redis、MySQL、RPC、并发。
- 项目是否上线、真实用户、指标、难点、怎么重构。
- 金融、客服、数据分析、AI Coding 等场景设计题。

## 3. 腾讯风格

### 高频权重

| 模块 | 权重 | 典型问法 |
|---|---:|---|
| 项目深挖 | 5 | 项目有没有真实用户？为什么没上线？核心难点是什么？ |
| Agent 治理 | 5 | 多 Agent 怎么编排？Agent 失败/中断怎么处理？ |
| 场景安全 | 5 | 跨境汇款场景下，Agent 超时/失败如何保证资金安全？ |
| RAG | 4 | 知识库怎么热更新？召回张冠李戴怎么办？ |
| 后端基础 | 4 | Redis、MySQL、MQ、并发控制、设计模式 |
| 手撕代码 | 3 | DFS、数组、字符串、SQL 或简单工程题 |

### 复习策略

腾讯更看重“你能不能把 AI 应用放进真实业务系统”。答题时不要只讲模型，要讲：

- 用户身份与权限。
- 工具调用幂等。
- 失败重试是否安全。
- 资金/订单/数据修改是否需要确认。
- 系统异常如何降级。
- 是否有审计和回滚。

### 典型追问模板

```text
你做的 Agent 有没有上线？
  -> 没上线为什么？
  -> 如果上线会遇到什么风险？
  -> 工具调用失败怎么办？
  -> 如果是资金场景，能不能自动重试？
  -> 如何保证不会重复扣款或重复提交？
```

| 多模型架构 | 4 | 新模型接入是否需要大改？模型路由怎么做？ |

| 后端中间件 | 4 | Redis 缓存问题、分布式锁、Session、RPC/HTTP |

### 复习策略

阿里类面试常把 AI 应用当成一个平台或工程系统来问。回答时要强调：

- 模块解耦。
- 插件化工具注册。
- 模型网关。
- 配置化 Prompt。
- 可观测性。
- 版本管理。
- 可扩展性。

  -> 新增一个工具要不要改代码？
  -> 如果重新设计，你会怎么平台化？

- Python 基础题能快速答。

- 向量相似度指标。
- 检索策略对比。
- 新功能接入流程。

## 6. 字节风格

### 高频权重

| 模块 | 权重 | 典型问法 |
|---|---:|---|
| 项目深挖 | 5 | 最有挑战的 AI 项目是什么？指标如何？ |
| Trade-off | 5 | 为什么这么选型？对比过什么方案？ |
| 性能与成本 | 5 | 延迟、吞吐、成本怎么优化？ |
| RAG/Agent 工程题 | 4 | 实现简易 RAG/Agent，或讲核心链路 |
| 手撕代码 | 4 | LeetCode 中等题、小型工程题 |

### 复习策略

字节风格通常节奏快、追问密。回答要短、准、有指标：

- 背熟项目 2 分钟版。
- 每个难点按“现象 -> 根因 -> 方案 -> 效果”讲。
- 准备性能优化和成本优化。
- 会写简化版 RAG pipeline 或工具调用伪代码。

  -> 指标提升多少？
  -> 如果 QPS 提高 10 倍怎么办？
  -> 成本怎么控制？

## 7. 美团/京东风格

### 高频权重

| 模块 | 权重 | 典型问法 |
|---|---:|---|
| 业务系统落地 | 5 | AI 如何嵌入现有业务流程？ |
| 后端基础 | 5 | 数据库、缓存、MQ、接口稳定性 |
| RAG/客服 | 4 | 知识库问答、智能客服、工单流转 |
| 稳定性 | 4 | 超时、重试、降级、监控 |
| 项目复盘 | 4 | 遇到的问题和优化 |

### 复习策略

这类面试里，AI 只是业务系统的一部分。要能讲清楚：

- AI 结果如何进入业务流程。
- 哪些动作允许自动化。
- 哪些必须人工确认。
- 失败时如何回退。
- 如何和老系统集成。

| 模块 | 权重 | 典型问法 |
|---|---:|---|
| 平台架构 | 5 | 多租户、权限、审计、服务化 |

### 复习策略

平台型岗位要少讲 Demo，多讲工程边界：

- tenant_id、acl、quota。
- Prompt/model/tool 版本管理。
- OpenAPI 转 tool。
- MCP server 治理。
- trace、审计、计费。

## 9. 初创/AI 产品公司风格

### 高频权重

| 模块 | 权重 | 典型问法 |
|---|---:|---|
| 快速落地 | 5 | 多久能做出 Demo？怎么从 Demo 到生产？ |
| LangChain/LangGraph | 4 | 用过哪些组件？踩过什么坑？ |
| RAG 效果 | 4 | 如何提升问答质量？ |
| Agent 产品体验 | 4 | 多轮、记忆、工具调用如何设计？ |
| 成本控制 | 4 | token 成本、模型选择、缓存 |

### 复习策略

初创更看重你能不能快速做东西，同时知道 Demo 和生产的差距。回答要兼顾速度和边界：

- 原型用框架快速搭。
- 生产加权限、日志、评估、降级。
- 先做受控流程，再逐步增加 Agent 自主性。

## 11. 临面押题

### 必背 10 题

1. 介绍一个你做过的大模型应用项目。
2. RAG 的完整链路是什么？
3. RAG 召回不准怎么优化？
4. Agent 和普通 Chatbot 有什么区别？
5. Agent 如何管理状态和上下文？
6. 工具调用如何保证安全？
7. 如何处理 Agent 失败、中断和重试？
8. SSE 流式输出怎么实现？
9. OpenAPI、RPC、MCP 的关系是什么？
10. 如果重新设计你的项目，你会怎么优化？

### 高压追问 10 题

1. 你的项目有真实用户吗？没有上线为什么？
2. 你怎么证明 RAG 效果变好了？
3. 如果检索到无权限文档怎么办？
4. 如果 Agent 重复调用扣款接口怎么办？
5. 如果工具调用超时了，能不能自动重试？
6. 如果 QPS 提升 10 倍，瓶颈在哪里？
7. 如果模型输出 JSON 错了怎么办？
8. 如果文档每分钟更新，RAG 怎么不停服？
9. 如果新增一个模型，架构要改多少？
10. 如果新增一个工具，如何注册、发现、鉴权和审计？
