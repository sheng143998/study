## 2. 30 分钟一面代码套卷

### 2.1 题目 1：LRU Cache

面试官问法：

```text
请实现一个 LRU Cache，支持 get 和 put，容量满时淘汰最久未使用的 key。
```

候选人澄清：

```text
我确认一下：get 不存在返回 None 可以吗？put 已存在 key 时需要更新并移动到最新位置，对吗？容量是正整数吗？
```

讲思路：

```text
我用 OrderedDict 实现。dict 负责 O(1) 查找，顺序表维护访问顺序。get 命中后 move_to_end，put 后如果超过容量就 popitem(last=False) 淘汰最旧元素。
```

代码：

```python
from collections import OrderedDict


class LRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.data = OrderedDict()

    def get(self, key: str):
        if key not in self.data:
            return None
        self.data.move_to_end(key)
        return self.data[key]

    def put(self, key: str, value) -> None:
        if key in self.data:
            self.data.move_to_end(key)
        self.data[key] = value
        if len(self.data) > self.capacity:
            self.data.popitem(last=False)
```

自测：

```python
cache = LRUCache(2)
cache.put("a", 1)
cache.put("b", 2)
assert cache.get("a") == 1
cache.put("c", 3)
assert cache.get("b") is None
```

生产增强：

```text
如果用于大模型响应缓存，还要加 TTL、最大内存、key 规范化、线程安全和缓存击穿保护。分布式场景会放 Redis。
```

### 2.2 题目 2：滑动窗口限流

面试官问法：

```text
实现一个用户级限流器，限制每个用户 60 秒内最多请求 100 次。
```

澄清：

```text
是单机内存版即可吗？时间窗口按当前时间滑动，不是固定自然分钟，对吗？
```

代码：

```python
import time
from collections import defaultdict, deque


class SlidingWindowLimiter:
    def __init__(self, max_requests: int, window_seconds: int):
        self.max_requests = max_requests
        self.window_seconds = window_seconds
        self.records = defaultdict(deque)

    def allow(self, user_id: str) -> bool:
        now = time.time()
        q = self.records[user_id]
        while q and now - q[0] >= self.window_seconds:
            q.popleft()
        if len(q) >= self.max_requests:
            return False
        q.append(now)
        return True
```

解释：

```text
每个用户维护一个 deque，只保存窗口内请求时间。过期请求会被弹出，所以单次操作均摊 O(1)。
```

AI 场景扩展：

```text
大模型网关里可以按 user、tenant、model、tool 多维限流，也可以按 token 预算限流。
```

## 3. 45 分钟 RAG 代码套卷

### 3.1 题目 1：多路召回合并去重

面试官问法：

```text
现在有向量召回和关键词召回两路结果，每个结果有 doc_id 和排名。请合并去重，返回 top_k。
```

澄清：

```text
两路分数是否可比？如果不可比，我会用排名融合，比如 reciprocal rank，而不是直接加原始分数。
```

代码：

```python
from dataclasses import dataclass


@dataclass
class Doc:
    doc_id: str
    text: str
    score: float = 0.0


def merge_by_rank(vector_docs: list[Doc], keyword_docs: list[Doc], top_k: int) -> list[Doc]:
    merged = {}

    for rank, doc in enumerate(vector_docs):
        merged.setdefault(doc.doc_id, Doc(doc.doc_id, doc.text, 0.0))
        merged[doc.doc_id].score += 1.0 / (rank + 1)

    for rank, doc in enumerate(keyword_docs):
        merged.setdefault(doc.doc_id, Doc(doc.doc_id, doc.text, 0.0))
        merged[doc.doc_id].score += 1.0 / (rank + 1)

    return sorted(merged.values(), key=lambda d: d.score, reverse=True)[:top_k]
```

追问：为什么不用原始分数相加？

```text
向量相似度和 BM25 分数分布不同，直接相加可能不公平。用排名融合可以避免分数尺度不一致的问题。
```

### 3.2 题目 2：引用编号校验

面试官问法：

```text
RAG 答案里引用格式是 [1] [2]，请检查答案里有没有引用不存在的 source。
```

代码：

```python
import re


def validate_citations(answer: str, source_count: int) -> bool:
    refs = re.findall(r"\[(\d+)\]", answer)
    return all(1 <= int(ref) <= source_count for ref in refs)
```

追问：这样能防幻觉吗？

```text
不能完全防。它只能防引用编号不存在。更严格要做 claim 到 source 的一致性校验，或者要求答案每个关键结论都绑定 source_id。
```

### 3.3 题目 3：文档增量更新

面试官问法：

```text
知识库每天同步一次文档，请找出新增、删除和更新的文档。
```

代码：

```python
import hashlib


def sha256(text: str) -> str:
    return hashlib.sha256(text.encode("utf-8")).hexdigest()


def diff_docs(old_docs: dict[str, str], new_docs: dict[str, str]) -> dict:
    old_ids = set(old_docs)
    new_ids = set(new_docs)
    added = new_ids - old_ids
    deleted = old_ids - new_ids
    updated = {
        doc_id
        for doc_id in old_ids & new_ids
        if sha256(old_docs[doc_id]) != sha256(new_docs[doc_id])
    }
    return {"added": added, "updated": updated, "deleted": deleted}
```

生产增强：

```text
真实知识库还要考虑 chunk 级别更新、索引原子切换、旧版本回滚和权限 metadata 同步。
```

## 4. 45 分钟 Agent / Tool 代码套卷

### 4.1 题目 1：Tool 参数校验

面试官问法：

```text
模型输出了工具调用参数，请根据 schema 做一个简单校验。
```

代码：

```python
def validate_args(args: dict, schema: dict) -> tuple[bool, str]:
    required = schema.get("required", [])
    properties = schema.get("properties", {})

    for field in required:
        if field not in args:
            return False, f"missing required field: {field}"

    for key, value in args.items():
        if key not in properties:
            return False, f"unknown field: {key}"
        typ = properties[key].get("type")
        if typ == "string" and not isinstance(value, str):
            return False, f"{key} should be string"
        if typ == "integer" and not isinstance(value, int):
            return False, f"{key} should be integer"

    return True, ""
```

追问：生产环境怎么做？

```text
生产里用 JSON Schema/Pydantic 等成熟库。更重要的是敏感字段不能信任模型生成，比如 user_id 和 tenant_id 应该来自服务端上下文。
```

### 4.2 题目 2：Agent 最大步数

面试官问法：

```text
写一个 Agent 循环，最多执行 max_steps 步，防止死循环。
```

代码：

```python
def run_agent(user_input: str, planner, tools: dict, max_steps: int = 5):
    state = {"input": user_input, "steps": []}

    for _ in range(max_steps):
        action = planner.next_action(state)
        if action["type"] == "finish":
            return action["answer"]

        if action["type"] == "tool":
            tool_name = action["tool"]
            if tool_name not in tools:
                state["steps"].append({"error": f"unknown tool {tool_name}"})
                continue
            result = tools[tool_name](**action.get("args", {}))
            state["steps"].append({"tool": tool_name, "result": result})

    return "任务执行步数过多，已停止。"
```

追问：只限制步数够吗？

```text
不够。还要做重复动作检测、工具调用超时、权限校验、人工确认和 trace 记录。
```

### 4.3 题目 3：Tool Call 去重

面试官问法：

```text
如何避免 Agent 在短时间内重复调用同一个工具和同一组参数？
```

代码：

```python
import hashlib
import json
import time


class ToolCallDeduper:
    def __init__(self, ttl_seconds: int = 60):
        self.ttl = ttl_seconds
        self.seen = {}

    def make_key(self, tool_name: str, args: dict) -> str:
        raw = json.dumps({"tool": tool_name, "args": args}, sort_keys=True)
        return hashlib.sha256(raw.encode("utf-8")).hexdigest()

    def is_duplicate(self, tool_name: str, args: dict) -> bool:
        now = time.time()
        key = self.make_key(tool_name, args)
        self.seen = {k: v for k, v in self.seen.items() if v > now}
        if key in self.seen:
            return True
        self.seen[key] = now + self.ttl
        return False
```

## 5. 60 分钟 Python 后端套卷

### 5.1 题目 1：并发执行器

面试官问法：

```text
现在要并发调用多个检索源，但最多同时 3 个请求，请实现。
```

代码：

```python
import asyncio


async def run_with_limit(coros, limit: int):
    semaphore = asyncio.Semaphore(limit)

    async def wrapper(coro):
        async with semaphore:
            return await coro

    return await asyncio.gather(*(wrapper(coro) for coro in coros), return_exceptions=True)
```

追问：为什么 return_exceptions=True？

```text
因为多路召回里某一路失败不应该拖垮全部结果。返回异常后可以记录日志，并让其他召回结果继续参与排序。
```

### 5.2 题目 2：SSE 流式生成器

面试官问法：

```text
写一个 SSE 生成器，把模型流式 token 返回给前端。
```

代码：

```python
import json


async def sse_stream(llm_stream):
    try:
        async for token in llm_stream:
            payload = json.dumps({"type": "delta", "content": token}, ensure_ascii=False)
            yield f"data: {payload}\n\n"
        yield 'data: {"type": "done"}\n\n'
    except Exception as exc:
        payload = json.dumps({"type": "error", "message": str(exc)}, ensure_ascii=False)
        yield f"data: {payload}\n\n"
```

追问：用户断开连接怎么办？

```text
FastAPI 里可以检测 request.is_disconnected，断开后停止生成并取消下游任务。如果底层模型 API 不支持取消，也要停止继续写响应并记录 client_cancelled。
```

async def call_with_timeout(coro, timeout_seconds: float):

## 6. 60 分钟模型网关 / 平台套卷

### 6.1 题目 1：模型路由

面试官问法：

```text
设计一个简单模型路由函数，根据任务类型、优先级和上下文长度选择模型。
```

代码：

```python
def route_model(request: dict) -> str:
    task_type = request.get("task_type")
    priority = request.get("priority", "normal")
    estimated_tokens = request.get("estimated_tokens", 0)

    if priority == "high":
        return "strong-model"
    if estimated_tokens > 8000:
        return "long-context-model"
    if task_type in {"rewrite", "classification", "format"}:
        return "cheap-model"
    return "default-model"
```

追问：如何证明路由合理？

```text
先用离线评测比较不同模型在各类任务上的质量、延迟和成本，再小流量灰度。路由策略必须有回滚机制和指标监控。
```

### 6.2 题目 2：Prompt 版本选择

面试官问法：

```text
做 Prompt A/B 实验，如何让同一用户稳定命中同一版本？
```

代码：

```python
import hashlib


def choose_variant(user_id: str, variants: list[str]) -> str:
    digest = hashlib.md5(user_id.encode("utf-8")).hexdigest()
    bucket = int(digest[:8], 16)
    return variants[bucket % len(variants)]
```

追问：如何支持不同流量比例？

```text
可以把 hash 映射到 0-9999 的 bucket，再按配置比例划分区间，比如 A 70%、B 30%。同时支持白名单、黑名单和一键回滚。
```

### 6.3 题目 3：SQL 只读校验

面试官问法：

```text
Text-to-SQL Agent 生成 SQL 后，如何做只读校验？
```

代码：

```python
import re


FORBIDDEN = {
    "insert", "update", "delete", "drop", "alter",
    "truncate", "create", "replace", "merge", "grant", "revoke",
}


def is_readonly_sql(sql: str) -> bool:
    normalized = re.sub(r"\s+", " ", sql.strip().lower())
    if not normalized.startswith("select"):
        return False
    tokens = set(re.findall(r"[a-z_]+", normalized))
    return not (tokens & FORBIDDEN)
```

追问：正则够吗？

```text
不够。生产里要用 SQL parser，并结合表级权限、行级权限、LIMIT、超时和审计日志。正则只能作为面试版或第一层防护。
```
